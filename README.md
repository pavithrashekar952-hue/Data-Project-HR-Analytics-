# Data-Project-HR-Analytics-
   This repository contains HR datasets and analysis work focused on employee demographics, hiring trends, and attrition patterns. Using Power BI.
the project explores:

Workforce growth and hiring rates across years

Attrition analysis with key risk factors

Data cleaning and validation for consistency

Visual dashboards and executive summaries for decision‑making

The repository also includes supporting documentation (PPT) to present insights clearly for stakeholders.
